**[ytmtui](https://github.com/Itthiago034/ytmtui)** é um cliente de **YouTube Music para o terminal**, escrito em Rust com Ratatui:

- 🎨 Temas com escala de cores própria, capa do álbum no terminal (Kitty/Sixel/iTerm2) e visualizador de espectro em tempo real
- 🔍 Busca unificada — músicas, artistas, álbuns e playlists em uma lista só
- 🎤 Letras sincronizadas em modo karaokê
- 📻 Rádio de músicas semelhantes, como no YT Music
- 🔑 Login com uma tecla, importando a sessão do seu navegador
