## Featured project

### [mcp-crunchyroll](https://github.com/Itthiago034/mcp-crunchyroll)

An unofficial [Model Context Protocol](https://modelcontextprotocol.io/) server that lets AI agents
search the Crunchyroll catalog, read your watchlist and history, and update your account.

- Sign-in happens only in a managed browser, so credentials never pass through tool arguments
- Closed tool schemas; uncertain writes fail closed instead of retrying blindly
- CI on Node.js 18, 20 and 22

`TypeScript` `Node.js` `MCP` `Chrome DevTools Protocol`
